# SteadyStream brand assets

Source: official SteadyStream TV marketing app (`Travsingletary/steadystreamtv` lovable-uploads).

## Palette (from SteadyStream CSS / tailwind)

| Token | Hex | Role |
| --- | --- | --- |
| Black | `#000000` | Primary background |
| Dark | `#0F0F0F` / `#121212` / `#181818` | Surfaces |
| Gold | `#D4AF37` | Primary accent |
| Gold mid | `#CFB53B` | Buttons / active |
| Gold dark | `#B8860B` | Hover / depth |
| Bronze | `#CD7F32` | Secondary accent |
| Warm sand | `#C0A080` | Secondary text / borders |

App CSS maps legacy `ink` / `ember` / `sand` token **names** to this SteadyStream palette so existing components pick up the brand without a mass rename.
